# Patient Information Management System

This project is a web-based patient information management system developed as a healthcare information system practice project.  
It focuses on patient record management, database-backed data storage, search, filtering, and pagination.

本專案為醫療資料管理系統實作，主要模擬病患資料的建置、查詢、修改與管理流程。專案重點不在宣稱符合完整電子病歷標準，而是透過 Web 系統與資料庫實作，理解醫療資料在資訊系統中的儲存、查詢與管理方式。

## Project Purpose

The purpose of this project is to practice how healthcare-related data can be managed through a web application and relational database.

This project connects to the course **Electronic Medical Records** by implementing a simplified patient information management workflow.

## Features

- Patient record management
- Patient data search and filtering
- Pagination for patient list display
- Database-backed data storage
- Web-based user interface
- Basic medical information system workflow practice

## Tech Stack

- ASP.NET MVC
- C#
- SQL Server / T-SQL
- HTML
- CSS
- JavaScript

## What I Learned

Through this project, I practiced how to connect a web application with a database and how to manage structured patient-related data.  
I also learned that healthcare information systems require not only interface design, but also clear data structure, search logic, and careful handling of medical records.

## Notes

This project is a learning-oriented healthcare information system prototype.  
It does not claim to be a complete clinical EMR system or a standard-compliant HL7 / FHIR implementation.
